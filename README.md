# 倾向自评问卷

一个纯前端的心理倾向自评网页。所有作答仅在本页面内计算，不采集、不上传、不存储。

## 主要内容

- 48 题、6 个维度（D / sub / S / M / SW / BR），5 点量表
- 每维度含 1 道反向题，用于识别敷衍或讨好性作答
- 结果页给出类型概括、维度分析、雷达图与协商沟通自评清单
- 18+ 年龄确认、键盘作答（数字键 1–5、方向键翻题）

线上演示：https://test.songtears.com/

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建或服务端。

## 回归测试

```bash
python tests/run_all.py      # 四层回归：结构 / 计分 / 端到端人格模拟 / UI 静态
python tests/verify_gate.py  # 门禁体检：故障注入，验证检查器本身仍有效（约 20 秒）
```

- `tests/run_all.py`：改动 `index.html` 后必须跑，四层全绿才允许交付。
- `tests/verify_gate.py`：改动任何测试脚本后必须跑。它把 10 类历史 bug 植入临时副本，确认门禁仍能拦截——防止"全绿"变成虚假安全感。

依赖：Python 3 与 Node.js（脚本内使用绝对路径，见 `tests/run_all.py` 顶部配置）。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 单文件应用：HTML / CSS / JS 全部内联 |
| `tests/` | 回归测试与门禁体检 |
| `DESIGN_CHECKLIST.md` | 网页/UI 任务完成前的八维度自查清单 |
| `deploy_bdsmtest.py` | 部署脚本（凭据不随仓库提供，需自行配置宝塔面板 API） |

## 说明

本问卷用于自我探索，不是心理学诊断，也未经过信效度检验。所有活动应建立在安全、理智、知情同意的基础上。
